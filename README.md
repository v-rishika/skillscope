# SkillScope

SkillScope is a career guidance web app that helps students explore job roles, analyze resumes, and understand which skills they need to improve.

### Features
- **Skill Analyzer:** Finds suitable job roles based on the user's skills.
- **AI Career Guide:** Provides personalized career suggestions using Gemini AI.
- **Resume Analyzer:** Extracts skills from resumes and provides an ATS-style score.
- **Job Description Matcher:** Compares a resume with a job description to identify matching and missing skills.

### Tech Stack
Python, Streamlit, Pandas, Google Gemini API, SQLite, HTML/CSS.

### About
This project was built to help students understand their career options and identify skill gaps before applying for jobs.
